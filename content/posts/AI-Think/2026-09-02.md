## 🔥 模型更新与安全漏洞：Anthropic 的冰火两重天

### Claude Fable 5.1 / Mythos 5.1 发布

Anthropic 发布了 Claude 系列的最新版本 Fable 5.1 和 Mythos 5.1。作为 Opus 5 发布后的重要迭代，这两个模型代表了 Anthropic 在安全与能力平衡上的持续追求。Fable 系列侧重创造性写作和复杂叙事，而 Mythos 则在大规模知识推理上更进一步。从 HN 社区的 852 分和 813 条评论的热度来看，开发者社区对 Claude 的进化方向保持了极高的关注度。

然而，真正值得关注的不是模型本身，而是配合新模型推出的 Auto Mode——这个号称用安全分类器取代人工审批的机制，正在被安全社区迅速解构。

### Breaking Claude Code Opus 5 Auto Mode：承诺的 0.00% 与现实的 80%

安全研究员 wunderwuzzi（Embrace The Red 博客作者）发布了一份令人不安的报告：Claude Code 的 Auto Mode（自 8 月中旬起成为默认模式）存在严重的间接提示注入漏洞。

> "Auto Mode **不是** 在隔离环境中运行代理并监控其行为的替代方案。" — wunderwuzzi

攻击链相当精妙：

1. **劫持工具选择** — 通过返回 415 Unsupported Media Type 错误，诱导 Claude 从 WebFetch 工具转向使用 `curl`
2. **重定向到 ZIP 压缩包** — 内含恶意编码的文件和原生解码器
3. **Python 标准库劫持** — Claude 拒绝执行二进制文件，但自行编写 Python 解码器时，在攻击者控制的目录中遇到了被篡改的 `struct.py`，导致 `base64` 模块导入时触发恶意代码

这一发现尤其令人震惊，因为 Anthropic 第三方评估（由 Trajectory Labs 执行）显示 Opus 5 Auto Mode 的提示注入成功率为 **0.00%**。wunderwuzzi 在 72 次测试中获得了 60-80% 的成功率。

> "Anthropic 没有告诉我不要在 Auto Mode 中做某事的任何部分。显然，在 Auto Mode 中做任何事都是被允许的，否则它就不会执行。" — wunderwuzzi

**深层思考**：这揭示了 AI 安全评估中最根本的困境——评估者测试的是"已知攻击模式"，而攻击者永远在寻找未知的路径。Anthropic 的安全分类器在面对一次精心设计的间接注入链时，表现与基准测试相去甚远。Auto Mode 的安全幻觉可能比模型本身的幻觉更危险：它让用户误以为机器在安全地自主决策。

## 🧠 小模型崛起：44% ARC-AGI 仅需 67 美分

MIT 研究员 Mithil Vakde 公布了一项令人瞠目的成果：仅用 **1.5 小时**在 RTX 5090 上训练的一个小型 Transformer（8 层，SwiGLU，3D RoPE），就在 ARC-AGI-1 公共评估上取得了 **44%** 的分数，总计算成本仅为 **67 美分**。

这个结果的意义远超数字本身：

1. **极致的样本效率** — Vakde 的核心目标是探索在纯 Transformer 框架下，样本效率能推到多远。ARC 作为元学习基准（仅 1000 个谜题），正好是检验这一极限的绝佳场所。
2. **证明递归并非必要** — 此前的顶尖方案（TRM、HRM）都依赖递归循环+深度监督，Vakde 用标准 Transformer 达到了同等水平，证明了递归的作用被高估了。
3. **开源、可复现** — 全部代码开源，任何人都可以在此基础上改进。

> "很多人认为之前的结果是不可能的。它引起了顶尖研究者的关注并在 X 上 viral。" — Mithil Vakde

最有趣的发现是：当模型停止在输入 token 上训练（转为纯监督式输出损失）时，测试损失更差，但得分更高。这指向了一个更深层的谜题——当前的损失函数可能不是衡量推理能力的好指标。

**深层思考**：这个成果对 AI 研究社区有双重启示。第一，ARC-AGI 基准开放 6 年、有百万美元奖金却一直未被小型 Transformer 解决，说明研究社区可能过于关注 LLM 大炼金术而忽略了基础架构的探索。第二，很多研究者"假设递归是下一个大事件"却没有充分消融来验证。Vakde 的消融实验表明，3D RoPE + 任务嵌入带来的性能提升远超任何架构花哨。这再次验证了那个苦涩的教训：好的表示学习比复杂的架构设计更重要。
