Bigger Models, Bigger Hallucinations: The Scale Trap

2026-06-21

本周的 AI 新闻揭示了一个日益显著的结构性矛盾：模型规模竞赛正在产生回报递减，而基础设施层正在重新设计以适应 agent 时代的到来。从 GPT-5.5 令人震惊的幻觉率到 Cloudflare 专为 AI agent 打造的临时账户，行业正在从"更大即更好"走向"更聪明即更好"，同时基础设施必须为无人值守的自主工作流重新架构。

“更大"的诅咒：当万亿参数模型不会说"不知道” 链接到标题

GPT-5.5 在 Artificial Analysis Omniscience 基准测试上的幻觉率高达 86%——比 MIT 开源许可的 GLM-5.2（28%）高出三倍，甚至远不如 Anthropic 的 Claude Fable 5（48%）和 Opus 4.8（36%）。这个数据出自 Oliver Shrimpton 的深度评测文章，它不仅令人震撼，更指向了一个深层次问题。

文章的核心洞察是现代 LLM 面临的"不可能三角"（trilemma）：原始能力、不确定性校准（幻觉率）和计算效率三者之间，目前没有任何模型能同时做到最优。DeepSeek V4 Pro（1.6T 参数）花了 3 分 26 秒的推理时间，生成了一个结构优美但完全错误的 Python 代码解决方案；而一个一半大小的模型（GLM-5.2，753B 参数）仅用 12 秒就识别出了技术上的不可能性。

“Moving forward, the industry cannot continue to train bigger and bigger models since their intelligence not only plateaus but often will get worse.”

这意味着什么？当 Claude Fable 5 发布仅三天就被美国政府限制使用——这是美国首次因国家安全理由禁止 AI 模型——我们正在进入一个能力与风险同步增长的时代。更大的模型在基准测试上更聪明，但在现实世界中更危险，因为它们学会了"自信地胡说"而非"诚实地说不知道"。

更深层的启示是：后训练（post-training）和数据配方的质量，正在取代参数数量成为模型竞争力的决定性因素。GLM-5.2 只有约 40B 活跃参数，却能接近 GPT-5.5 的智力指数得分，这本身就是对"规模崇拜"的有力反驳。

Agent 优先：Cloudflare 颠覆部署范式 链接到标题

当 Claude Fable 5 被限制使用、GPT-5.5 的可靠性受到质疑时，一个更具结构性的变化正在基础设施层面发生。Cloudflare 推出了 Temporary Accounts（临时账户）——专为 AI agent 设计的零摩擦部署方案。

核心机制极其简洁：Agent 只需运行 wrangler deploy --temporary，就能获得一个有效期为 60 分钟的临时 Cloudflare 账户，用于部署 Worker。如果开发者想保留这个部署，随时可以 claim；如果不 claim，60 分钟后自动销毁。

这个看似简单的功能背后是对 agent 工作流的深刻理解：

“Background AI sessions have no human in the loop, and are becoming the norm. Any auth step that needs a browser, a copy-paste, or ‘click here in 60 seconds’ means an agent gets stuck.”

Cloudflare 敏锐地捕捉到了三个关键洞察：

  1. 无人在环（no human in the loop）是 agent 的默认状态。任何需要浏览器点击的认证流程都会让 agent 死锁，并可能促使它选择其他平台部署。
  2. 试错是 agent 的超能力。Agent 需要 tight 的 write → deploy → verify 循环，需要廉价的、可丢弃的部署目标。
  3. Agent 平台正在构建自己的"开箱即用"部署管道。用户开始期望整个过程无需额外步骤或凭据——就像打开水龙头一样自然。

更值得注意的是，Cloudflare 还设计了让 Wrangler CLI 主动提示 agent 使用 --temporary 标志的机制——这意味着 AI agent 在第一次因无凭证而卡住时，能从错误消息中学习并自动纠正。这是一种"为机器设计的用户体验"（machine-first UX），与传统的"为人类设计的 UX"形成了鲜明对比。

Cloudflare 还与 Stripe 合作设计了让 agent 自动创建账户、启动订阅、注册域名、获取 API token 的新协议。Agent-ready 正在成为基础设施的新基线要求。

推理成本的"餐巾纸数学"：AI 公司的生存算账 链接到标题

在模型质量受到质疑的同时，Srijan Paul 的文章为 AI 公司提供了一份极其实用的经济模型。它以"餐巾纸上的估算"为风格，推导出一张 NVIDIA B200 GPU 能为多少用户提供服务。

核心结论令人深思：

  • 一块价格约 $40,000 的 B200 GPU，在 100% 占空比下，每个用户生命周期成本高达 $6,000。
  • 但实际场景中，聊天应用的用户约 80% 时间在阅读而非提示，GPU 的占空比仅约 20%。因此一块芯片实际上可以舒适地为 300-800 名用户 提供服务。
  • 按云租赁算（B200 约 $4/小时），每用户每小时成本约 $0.013，折合每月约 $9.36。

“A Blackwell class GPU can crunch bytes 562 times faster than it can load them.”

这个 562:1 的计算/内存比率是理解一切推理成本的关键。对于使用 KV-cache 的自回归推理，成为瓶颈的永远是 内存带宽，而非计算能力。一块 B200 从 VRAM 搬运 190GB 数据需要约 23.75ms，而真正用于计算的时间仅 0.5ms——计算核心 98% 的时间在空转。

这意味着 GPU 供应商的下一步竞争焦点将从 FLOPS 转向内存带宽和容量。HBM4、CXL 等技术的重要性将远超核心数量的增长。对于模型架构师而言，降低 KV-cache 压力（如 GQA、MQA 或更激进的线性注意力机制）将成为比训练更大的模型更有效的成本优化策略。

当 AI Agent 学会"黑"你的代码：攻防对称性 链接到标题

一支名为 ArgusRed 的团队做了一件发人深省的事：后训练了一个拒绝进行渗透测试的模型，让它主动攻击系统、发现漏洞。这个项目的核心理念是：目前 Anthropic 和 OpenAI 的公开模型都设置了严格的防护栏，拒绝"进攻性"任务；而它们的网络安全专用模型又仅限于大型企业使用。这导致中小企业在安全防御上存在巨大空白。

“AI can be used as both an adversarial and defensive tool in the world of cyber. A worst case outcome is if only the adversaries have access.”

ArgusRed 的模型基于十年的 CTF（夺旗赛）题解数据进行后训练，提供两种模式：

  • Security Scan（安全扫描）：对本地代码库进行只读审计，仅报告能定位到具体文件和行号的安全问题
  • Pen Test（渗透测试）：在沙盒环境中主动攻击实时系统，通过实际运行 exploit 来证明每个漏洞的存在

这里的核心洞察是攻防对称性：如果只有攻击者拥有 AI 驱动的渗透测试能力，网络安全格局将严重倾斜。ArgusRed 的贡献不仅仅是技术方案，更是对 AI 安全范式的一次重新定位——拒绝（refusal）不是安全的正解，受控的能力开放才是。

作为例证，他们对 Google 开源的 Bank of Anthos 进行扫描，发现了一个整数溢出漏洞：amount 的类型是 int，而 amount + fee 可以溢出为负数，导致余额检查被绕过。这种实际漏洞的发现，远比基于"信心分数"的模糊建议更有价值。

这引出一个更深层的问题：当我们讨论 AI 安全性时，我们到底在保护什么？ 是保护模型不被滥用，还是保护用户免受攻击？前者导向更强的拒绝机制，后者导向更精准的能力授予（capability gating）。ArgusRed 选择了后者，并为此构建了一个有意义的工程方案。

结语 链接到标题

本周的 AI 新闻拼接在一起，揭示了一个更宏大的叙事：AI 行业正在从"大就是好"的狂热中清醒，进入一个更务实的结构调整期。

  • 在模型层面，GPT-5.5 的幻觉危机和 GLM-5.2 的崛起表明，质量胜过规模的时代已经到来。后训练策略、数据质量和校准能力正在取代参数数量成为竞争核心。
  • 在基础设施层面，Cloudflare 的临时账户是 agent 时代基础设施民主化的第一个信号——为机器设计的 UX 正在成为新的竞争壁垒。
  • 在经济层面，推理成本的"餐巾纸数学"提醒我们，GPU 的内存带宽瓶颈意味着 AI 公司必须同时优化模型架构和硬件利用率，才能实现可持续的商业模式。
  • 在安全层面，ArgusRed 重新定义了 AI 安全的边界——拒绝不是安全的终极答案，受控的能力授权才是。

当 Claude Fable 5 因单一 jailbreak 而被美国政府限制使用，当 GPT-5.5 以 86% 的幻觉率成为"最自信的胡说者"，我们正在见证一个行业的脱胎换骨：从追求下一个 AGI 里程碑，到建造真正可靠、可部署、可负担的 AI 系统。
