一个有趣的历史巧合：OpenAI 和 Anthropic 几乎在同一 24 小时内发布了各自的最新旗舰模型。这不是单纯的版本迭代，而是两套完全不同理念的对决。

Anthropic Claude Opus 5.5 的核心叙事是"效率革命"。它宣称以 Opus 5 的 40% 成本实现更高性能，实际定价输入 $4/M、输出 $20/M，缓存读取仅 $0.20/M（比 Opus 5 降低 60%）。一个早期测试者用它完成了 68 万行代码的迁移——“本应耗费工程团队数周的工作量，一天内完成”。在 HAProxy（C 语言负载均衡软件）到 Rust 的重写测试中，Opus 5.5 仅用 9.5 小时就通过了几乎所有回归测试，比 Fable 5.1 快 2.5 小时，成本低 51%。

“It writes the way I do.” ——早期测试者对 Opus 5.5 写作风格的评价

但 Opus 5.5 真正的亮点可能是其安全架构。它经过了 Automated Behavioral Audit（Anthropic 最全面的对齐测试套件，涵盖数千种模拟场景），以最高分通过。它还被 Frontier Design 和 METR 等外部评估机构测试——这是 Anthropic 自"呼吁放缓前沿模型发展"后的首次发布，安全叙事是其差异化核心。

反观 OpenAI GPT‑6 系列：Sol、Luna 和 Astra 三个变体覆盖不同能力层面。Astra 的表现尤为震撼——它破解了一则自 2005 年以来无人能解的德国陆军 Enigma 密文 MVUEH（1941 年 7 月 10 日发送），其密钥与已知的当日密钥完全不同（轮序 253 而非 512），且破解揭示了原始抄录中存在多处人为错误。更令人震惊的是，GPT-6 Astra 还获得了"驾驶汽车"的能力，在 DrivingBench 上取得了里程碑式结果。

一个 AI 破解 Enigma 的讽刺意味十足：二战时期，Alan Turing 在 Bletchley Park 用最早的计算机破解 Enigma；今天，另一个 AI 完成了同一位面的工作——只不过这次破解的不是纳粹密码，而是 80 年无人能解的"遗珠"。

同时，第三方模型 Mercury 2.5 达到 770 tokens/s 的推理速度，暗示着推理效率竞争已经成为模型军备竞赛的第三维度——不仅仅是"谁更聪明"，更是"谁更快更便宜"。

AI 科学家：Claude 发现新型酶系统，DNA 数据库里的 CRISPR 幽灵 链接到标题

来源

  • Claude discovers a novel enzyme system with CRISPR-like repeats — Anthropic | HN 讨论

Anthropic 在今天同时宣布了另一项重磅进展：他们组建了生命科学研究团队和实验室，专注于利用 Claude 进行基础生物学研究。其首批成果是 Claude 自主发现 了一个新型酶系统——阵列相关逆转录酶（Array-associated Reverse Transcriptase, ART）。

过程令人惊叹：Anthropic 的科学家给 Claude 下达了一条高级指令——“在 DNA 数据库中搜索有趣的新型逆转录酶”。Claude 随后调用了约 950 个 Agent、耗时 21 小时、消耗 2.1 亿个 token，在浩如烟海的 DNA 序列中锁定了一个异常模式：某个巨型噬菌体（jumbo phage）的逆转录酶基因旁，出现了一段重复性非编码 DNA 序列和一种功能未知的辅助蛋白。

这个发现的意义：Claude 看到的是人类科学家此前忽略的模式。CRISPR 本身最初也只是细菌 DNA 中的"异常重复序列"——直到科学家意识到它是对抗病毒的免疫系统。ART 系统的架构特性（逆转录酶 + DNA 重复序列阵列 + 辅助蛋白）只在少数已知的可编程系统中同时出现过，如 CRISPR、限制性内切酶等。它可能是下一个基因组编辑工具。

Feng Zhang（CRISPR 基因编辑先驱、MIT 教授）在审阅预印本后表示：

“这是 AI Agent 能够贡献于生物发现的一个激动人心的例子。识别出与逆转录酶相关的 RNA 重复阵列确实引人入胜，值得进一步研究。”

这标志着 AI 在科学发现中的角色正在发生质变：从"辅助工具"（帮助科学家分析数据）到"自主发现者"（在无人干预的情况下提出假设并验证）。950 个 Agent 并行工作 21 小时，完成的是一位博士后研究员数月的工作量。

在模型竞赛的白热化背后，Agent 基础设施层的创新同样值得关注。

Unreal Agent 提出了一个巧妙的洞察：传统 Agent 在工具调用时浪费了大量 token 和等待时间。他们的解决方案是将工具调用完全异步化——模型不必管理等待、轮询和心跳，而由 harness 层接管。这带来了两个好处：用户可以随时中断和引导 Agent（无需等待工具完成）；Agent 可以在模型推理之间调度更多有用的工具调用。实际效果：相比 Codex 成本降低 40%，相比 Pi 降低 20%。

Unreal Agent 的理念揭示了一个被忽视的事实：Agent 性能瓶颈往往不在模型本身，而在于模型与工具之间的通信架构设计。

Apple 的 LensVLM 则从一个完全不同的角度解决上下文窗口问题：它将长文本压缩成图像，然后只选择性展开相关页面。这种"先缩略、后聚焦"的策略，实际上模拟了人类阅读长文档的方式——先扫目录，再细读相关章节。9B 参数的模型规模意味着它可以在端侧运行，这对 Apple 的隐私优先叙事意义重大。

Google Gemini 3.8 TTS 展示了语音合成领域的跨越式进步——从预设语音到动态语音创作。用户可以"从零创建自定义角色语音"或"用自然语言提示词复现现有声音"。一对一的逐句导演模式允许控制节奏、情感甚至"真实对话声音"。内置的水印安全工具反映了合成语音滥用的担忧已经进入产品设计阶段。

与此同时，jyn.dev 的《Tokens too cheap to meter》一文精准捕捉了行业心态转变：当 tokens 的价格跌到"不值得计量"的程度时，整个应用架构范式都会改变——从"最小化 token 使用"变成"最大化 token 效用"。

信任悬崖：Claude Code 的遥测争议与安全审计的 AI 化 链接到标题

来源

  • Claude Code reads AGENTS.md only when telemetry is on | HN 讨论
  • Security auditing in the age of (good enough) AI — Trail of Bits | HN 讨论

Claude Code 的一个"feature"引发了一场信任危机：AGENTS.md（项目级 AI 指令文件）只在遥测开启时才会被读取。具体来说，W（插件的 isOnByDefault 值）是 false，而 B（isAvailable）依赖于一个名为 tengu_agents_md_mod 的远程功能开关——如果无法获取该开关，插件就不可用，即使本地存在 AGENTS.md 文件也永远不会被读取。

读取工作目录中的一个纯文本 Markdown 文件，完全不需要网络连接。但 Anthropic 选择了让它依赖于服务器端开关。

当用户设置 CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1 或 DISABLE_TELEMETRY=1 时，AGENTS.md 就无法加载。这引发了一个根本性的信任问题：用户本地的项目指令文件，为什么要通过网络才能激活？

反过来，Trail of Bits 展示了 AI Agent 的另一面——可以用于防御。他们对 Miden VM（零知识虚拟机）的安全审计中，让 Agent 花费 6 个月构建了 LSP 服务器、反编译器、静态分析引擎和 VM 执行器的 Lean 模型。这些工具发现了一个真实的安全漏洞（未验证的 prover 输入可伪造 Falcon 签名窃取资金），并产生了 95 个机器验证的正确性证明。

Trail of Bits 的案例提醒我们：AI Agent 的能力本身是中立工具——问题在于谁控制它、用于什么目的、在什么样的约束下运行。
